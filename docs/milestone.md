## Project Milestones

#### Milestone 0: Customer Data and Preference Modeling

Develop source code that represents core entities and value objects such as customers, consumption records, and style preferences based on user stories, following good development methodologies to ensure code quality.

Develop source code to implement the business logic for automatically analyzing customer preferences and generating personalized promotions. This milestone is feasible if good development practices are followed (creating issue tickets, branch development, Pull Request closure) and if it passes tests.
